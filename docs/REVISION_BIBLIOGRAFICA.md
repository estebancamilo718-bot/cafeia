# Revisión bibliográfica pendiente

Esto es una guía de trabajo, no una revisión bibliográfica terminada.

Buscar la publicación original y repositorio original de RoCoLe; verificar autores, año, licencia, especie de café, unidades de captura, significado de nombres y etiquetas. El ZIP recibido solo contiene imágenes en carpetas; no contiene metadatos ni licencia. No redistribuir imágenes en GitHub sin verificar la licencia.

Buscar artículos primarios sobre coffee leaf disease classification, RoCoLe, CNN, transfer learning. Para cada estudio anotar título, DOI/enlace, año, dataset/versión, clases, cantidad de imágenes, separación por hoja o planta, modelo, preprocesamiento, métricas y limitaciones.

No comparar porcentajes de artículos como si los experimentos fueran equivalentes cuando cambien las clases, la división o el dataset. Explicar esas diferencias en discusión. El objetivo inicial es documentar al menos 4–6 estudios relevantes como propuesta de trabajo, no como número impuesto por el profesor.
